# XP+ 2.1.0

XP+ 2.1.0 is the first stable promotion of the XP+ workstation line after
the AF-00..AF-10 capability program and the XP+-07..XP+-10 release gates.

## Verified
- local-first/offline operation;
- explicit ANALYSIS / WORKER / LIVE modes;
- no silent provider/model fallback;
- governed worker approval, recovery, verification and rollback;
- hybrid provider/model routing;
- conversational project orchestration;
- local loopback visual PWA;
- universal Plain Git / Node / Python / Node+PostgreSQL / Firebase-static fixtures;
- Segeran Jiwa Legacy and Next compatibility;
- side-by-side engine lifecycle and rc18.3 rollback origin;
- canonical version-derived fresh installer (`install.py`);
- preserved binding §14 / Zone-1 / Zone-2 / Evidence compatibility documentation.

## Boundaries
- production deployment automation is not part of XP+ v1;
- Firebase and Cloudflare are project concerns, not mandatory engine dependencies;
- LIVE/provider availability is external state and never silently replaced;
- destructive database actions remain approval-governed and project-specific.
