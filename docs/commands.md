# Commands

## `xp` — Menu Utama
- [1] Lanjutkan dari posisi terakhir
- [2] Scan hasil GPT terbaru
- [3] Pilih project lain
- [4] GPT baru / handoff
- [5] Status & audit
- [0] Keluar

## `xp pkg-build --repo <path> --spec <spec.json>`
Build paket dari spec. Output: `~/storage/downloads/Expert/XP_PKG_WORK_<project>_<milestone>.zip`

## `xp bundle --repo <path>`
Export context untuk AI baru. Output: `~/storage/downloads/Expert/XP_BUNDLE_<project>_<timestamp>.txt`. Lampirkan file ke chat AI baru (jangan paste manual).

## `xp help [topik]`
Tampilkan dokumentasi. Topik: quickstart, workflow, commands, concepts, project-setup, troubleshooting, architecture.

## `xp version`
Tampilkan versi aktif.
